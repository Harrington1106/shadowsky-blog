宝塔面板是一个装在 Linux 服务器上的 Web 管理面板。装好之后，建站、装环境、配证书、看监控这些操作都在浏览器里点，不用记命令。

它不适合所有场景，但对刚开始碰服务器的人来说，是绕开命令行门槛最快的一条路。

## 一、建站

这是宝塔最核心的功能。手动搭一个网站，大致要走这些步骤：

1. SSH 连上服务器
2. `apt install nginx`
3. `apt install mysql-server`，配置密码、权限、字符集
4. `apt install php-fpm php-mysql php-curl ...`，十几个扩展，少一个就报错
5. 写 Nginx 配置文件，一个分号错了就是 502
6. 用 certbot 申请 SSL 证书，还得自己盯着别过期

宝塔把这些收进了几个页面：

1. 登录面板
2. 软件商店 → 一键安装 LNMP（Linux + Nginx + MySQL + PHP）
3. 等 5 分钟，环境自动配好
4. 网站 → 添加站点 → 填域名
5. SSL → Let's Encrypt → 申请，证书自动装上，到期自动续

十分钟以内能走完，中间基本不会卡在环境问题上。

## 二、文件管理

宝塔自带在线文件管理器，日常够用：

- 拖拽上传，直接把文件从桌面拖进浏览器
- 在线编辑，双击文件改代码，带语法高亮
- 压缩解压，右键解压 ZIP / TAR
- 权限管理，777 和 755 不用背，勾复选框
- 远程下载，粘贴 URL 让服务器自己去下

网站搬家时这个功能最省事：旧站文件打包成 ZIP 传上来，右键解压就完了，不用再开 FTP 客户端。

## 三、计划任务

定时任务在面板里配置，到点自动执行。

最该先配的是备份。设成每天凌晨 3 点备份网站代码和数据库，再传到阿里云 OSS、腾讯云 COS 或 Google Drive，设一次就一直生效。服务器哪天出事，至少数据还在。

其他常用的几类：

| 任务 | 用途 |
|------|------|
| 日志切割 | 防止 nginx 日志把磁盘撑爆 |
| 释放内存 | 定时重启 PHP / MySQL，清理内存碎片 |
| 证书续期 | SSL 到期前自动续，宝塔默认已经会做 |
| URL 监控 | 定时检查网站是否在线，挂了发邮件 |

## 四、软件商店

面板内置了应用商店，装软件跟装手机 App 差不多：

| 软件 | 用途 |
|------|------|
| Redis | 缓存加速 |
| Docker 管理器 | 图形化管理 Docker 容器 |
| PM2 管理器 | 跑 Node.js 项目 |
| Fail2ban | 自动封禁暴力破解的 IP |
| Nginx WAF | Web 应用防火墙，部分功能付费 |

需要说明的是，商店里的东西主要面向简单场景。如果要做复杂的 Docker 编排，用 Portainer 或者直接敲命令行会更顺手。

## 五、监控与安全

面板首页是一块仪表盘，能看到 CPU 使用率、内存占用、磁盘读写、网络流量和负载。内存飙高的时候点进去就能看出是哪个进程在吃资源，可以直接结束掉。

安全相关的功能有三块：

- 系统防火墙，可视化配置端口规则，屏蔽指定 IP
- SSH 管理，改端口、禁用 root 登录、改成密钥登录
- 面板 SSL，给宝塔面板本身也配上 HTTPS

最后一条别跳过。面板本身就是一个能操作整台服务器的入口，裸 HTTP 暴露在公网上风险不小。

## 常用操作速查

| 需求 | 操作路径 |
|------|----------|
| 新建网站 | 网站 → 添加站点 → 填域名 |
| 配 HTTPS | 网站 → SSL → Let's Encrypt → 申请 |
| 改网站目录 | 网站 → 设置 → 网站目录 |
| 备份网站 | 计划任务 → 添加 → 备份网站 |
| 查看错误日志 | 网站 → 设置 → 错误日志 |
| 重启 Nginx | 首页 → 软件 → Nginx → 重启 |

## 小结

宝塔的价值在于把入门门槛压低：不用先学 Linux 命令就能建站，不用记配置语法就能配环境，也不容易忘记备份。

代价是你对系统的了解会停留在面板给你看到的那一层。等需要更精细的控制时，还是得回到命令行——但那时候你已经有一台在跑的服务器了，学起来有具体的东西可对照。
