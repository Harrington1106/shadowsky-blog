AWS 的免费套餐给 12 个月，配置够跑个人博客或者学 Linux。

需要注意的是它和国内云厂商的预付费不一样：AWS 是后付费，超出免费额度的部分直接从绑定的卡里扣，不会先问你。所以这篇的重点其实在第三节。

## 一、注册前的准备

门槛主要在身份和支付验证。

需要三样东西：

- 邮箱，Gmail 或 Outlook 都行
- 手机号，支持中国大陆的 `+86`
- Visa 或 Mastercard 的信用卡 / 借记卡，卡面上要有对应标志

注册时 AWS 会做一笔 1 美元的预授权来验证卡片有效性，之后会退还。纯银联卡不支持。

### 没有双币信用卡怎么办

两条路：

- 办一张 Visa / Mastercard 借记卡。中国银行、工商银行这些大行都能办，门槛比信用卡低很多，AWS 一样认
- 有 `.edu` 邮箱的话，可以申请 AWS Educate 账户，不用绑卡，但能用的资源有限

## 二、创建 EC2 实例

注册完进 EC2 控制台开机器。这一步每个选项都可能产生费用，慢一点。

### 区域

不是所有区域都在免费范围内，而且网络质量差别很大。

从国内连的话，推荐亚太地区的东京或新加坡；想要线路稳定一些，可以选美国西部（俄勒冈）。

### 镜像与实例类型

系统选 Debian 或 Ubuntu，确认下方标着 Free tier eligible。

实例类型必须是 `t2.micro` 或 `t3.micro`。只有带 Free tier eligible 标签的型号才免费，选错了就是按小时计费。

### 密钥对

创建并下载 `.pem` 私钥文件。

这是登录服务器的唯一凭证，AWS 自己不保存私钥，丢了就再也进不去了，只能重开实例。下载完立刻找个地方存好。

### 存储

免费套餐含 30GB EBS，但创建时默认只给 8GB。手动改成 30GB，反正都是免费额度内的。

## 三、三个扣费陷阱

AWS 免费套餐真正会让人意外扣费的就这三处。

### 不要开第二台

免费时长是每月 750 小时。一台机器全月不关是 24 × 31 = 744 小时，刚好在额度内。

同时开两台的话，半个月就把额度用完了，后面按小时收费。

### 不要留着闲置的公网 IP

弹性 IP（Elastic IP）只有绑在**正在运行**的实例上才免费。

也就是说，你把实例关机（Stop）了，或者解绑了 IP 但没释放（Release），这个闲置的 IP 就开始按小时扣钱。

新手直接用实例启动时分配的动态 Public IP 就够了，不用申请 Elastic IP。

### 不要超流量

每月 100GB 出站流量（Data Transfer Out），超出按 GB 计费。

个人博客、代码测试这类用途基本用不完。但如果拿来跑大流量下载或者多人共享代理，很容易超。

## 四、设置账单报警

前面三条靠自觉，这一条靠系统。

1. 控制台搜索 AWS Budgets
2. 创建一个 Cost budget（成本预算）
3. 阈值设成 $0.01 或 $1.00
4. 填上你的邮箱

设成一分钱，账户上只要产生任何费用就会立刻收到邮件。发现得早，及时关掉服务，损失就是几毛钱的事。

这一步花不了两分钟，但它是这套免费套餐里唯一能兜底的机制，别省。
