# 写文章工作流（Obsidian 端）

这个文件夹本身就是一个 Obsidian 库，同时也是站点的**草稿箱**
（`web/scripts/*` 里的 `DRAFTS_DIR` 默认就指这里）。所以 Obsidian 里存的文件，
发布台和命令行**立刻**就能看到，中间没有任何复制/同步步骤。

## 新建一篇

命令面板（`Ctrl+P`）→ **Templater: 新建：新文章**，依次回答：

| 问题 | 说明 |
|------|------|
| 文章标题 | 中文，显示在页面顶部 |
| 英文 slug | **线上地址 `/post/<日期>-<slug>`，发布后再改等于换地址、丢外链**。会校验：只能英文数字连字符、不能和已发布的文章或已有草稿撞名 |
| 分类 | 从 `../posts` 里现读出的分类清单里选，也可以新建 |
| 标签 | 逗号分隔（中英文逗号都行），可留空 |
| 封面图 | 可留空 —— 留空就用分类默认图 |

回车完文件自动改名成 `<日期>-<slug>.md`，光标停在正文第一行。

建议绑个快捷键：设置 → 快捷键 → 搜 `新建：新文章` → 绑 `Ctrl+Shift+N`。
之后开写一篇就是**一个键**（它自己会建空文件，不用先 `Ctrl+N`）。

> 命令面板里还有一条 **Templater: 套用模板：新文章** —— 那是把模板插进*当前*文件。
> 模板只在**空文件**上跑，对着写了一半的文章按会直接报错退出，不会动你的正文。

## 外观

主题是 **Phycat（物理猫）0.2.9**，从别的库搬过来的，和你其它库同一个版本。
只搬了 Obsidian 真正加载的 `manifest.json` + `theme.css`（外加 LICENSE）——
原目录里的 `.git`、捐赠二维码和高清截图共 1.2MB 都没要，
尤其 `.git` 不能带：它会在本仓库里套出一个嵌套 git。

这个主题内置了 5 段 **Style Settings** 配置，插件已经装上（1.0.9）：
设置 → 第三方插件 → **Style Settings**，里面能调配色、卡片布局、文章间距、标题样式。

Style Settings 自带中文词典，界面语言设成简体中文后它自己就是中文的，不用打补丁。
主题里 48 条 `title.zh` / 11 条 `description.zh` 也会跟着显示中文 ——
只有 4 个分组**标题**仍是英文（`🎨 Phycat color setting` 这种）：
插件只本地化 `title` / `description`，不认 `name.zh`，是上游的行为，不是配错了。

## 装了哪些插件

| 插件 | 版本 | 干什么 |
|------|------|--------|
| Templater | 2.24.3 | 上面那个「新建：新文章」模板 |
| Image auto upload | 4.1.0 | 粘贴图片自动传 PicList |
| Style Settings | 1.0.9 | 调 Phycat 主题 |
| Easy Typing | 6.0.9 | 中英文之间自动加空格、标点转换（它会跳过 frontmatter 和代码块） |
| Advanced Tables | 0.23.2 | 表格自动对齐，Tab 跳单元格 |
| Paste URL into selection | 1.11.4 | 选中文字直接粘 URL 变成链接 |
| Various Complements | 11.4.0 | 从库里已有的词自动补全（「宝塔面板」「反向代理」敲两字就出来） |

⚠ **有两个热门插件绝对不能装**：

- **Linter** —— 它会重排 YAML frontmatter，把 `tags: ["a","b"]` 拆成多行列表。
  线上解析器是逐行 `indexOf(':')` + 对 tags 直接 `JSON.parse`，一跑全站文章标签变空。
- **Obsidian Git** —— 这个库在 `shadowsky-blog` 仓库**里面**，
  它会对仓库根操作，一次自动提交能把 `web/` 的代码改动一起 commit 掉。

## 线上不认的 Markdown 语法

网站的渲染管线是纯 GFM（`lib/renderMarkdown.js` 里 `new Marked({breaks:true, gfm:true})`），
没挂任何扩展。Obsidian 里好看、但**发出去是乱的**：

| 写了没用 | 结果 |
|----------|------|
| `> [!NOTE]` callout | 变成普通引用块，还带着字面的 `[!NOTE]` |
| `==高亮==` | 原样显示等号 |
| `[[双链]]` / `![[图片]]` | 原样显示方括号 |
| `[^1]` 脚注 | 不渲染 |

能用的：表格、`~~删除线~~`、任务列表、`<details>`、B 站 iframe（白名单只放行 bilibili）。
想要「提示框」效果就照现有文章那样写 `> **TL;DR**：…`。

**这些不用死记** —— 发布台和 `publish-post` 会实时体检，写了就报，还告诉你会渲染成什么样。
体检规则（`web/scripts/lib/post-meta.mjs` 的 `lintBody`，共 7 条）：

| 报什么 | 为什么 |
|--------|--------|
| 正文 H1 和标题重复 | 页面顶部已有大标题，会出现两个 h1 |
| 整行粗体当小标题 | 没有标题样式、没有锚点、**不进目录** |
| 标题跳级（## → ####） | 目录缩进错乱 |
| 代码块没标语言 | 高亮不生效，退化成没配色的纯文本 |
| 图片缺 alt | 图挂了是一片空白，读屏软件也读不出 |
| 用了站点不认的语法 | 就是上面那张表，会告诉你具体渲染成什么 |
| 段落超过 180 字 | 手机上是一堵墙（现有文章最长 132 字） |

⚠ 这些检查都跑在**剥掉代码块和行内代码**的正文上 —— 写 Obsidian / Markdown 教程时，
正文里出现 `[[双链]]` 这类示例是内容，不会被误报。

## 界面语言

Obsidian 本体：设置 → 关于 → 语言 → **简体中文**。
`Image auto upload` 插件自带中文词典，跟着这个设置一起变，不用管。

Templater 没有 i18n，是用仓库里的脚本把 `main.js` 的文案替换成中文的。
**插件一升级，汉化会被官方版覆盖**，重跑一次即可：

```bash
node scripts/obsidian-i18n.mjs            # 打补丁
node scripts/obsidian-i18n.mjs --check    # 只体检，顺带列出没翻到的英文
node scripts/obsidian-i18n.mjs --restore  # 还原成官方原版
```

## 不用手写的三个字段

`excerpt` / `readTime` / `lastModified` **不要写**。发布脚本会算：
摘要从正文抽、阅读时长按中文 250 字/分 + 代码 15 行/分算、修改日期取发布当天。
手写这三个是上一版工作流最容易出错的地方。

`author` 模板已经填好，正常不用动。

## 图片

`Image auto upload` 插件照常用（走本机 PicList），粘贴即上传，正文里留的是图床外链。
**发布时脚本会把所有跨境图片抓下来转 webp、传到自家服务器**，
并把地址改写成 `/uploads/covers/<sha1>.webp` —— 这是在守站点那条「前端零跨境依赖」。

⚠ 抓不下来会**中止发布**（文章不上线），不会带着外链偷偷发。
跨境图床多半要过代理，带上再跑：

```bash
HTTPS_PROXY=http://127.0.0.1:7890 node scripts/publish-post.mjs <文件名>
```

## 正文写法

- **别再写一遍标题** —— 页面顶部已经有大标题了，正文里再来个 `# 标题` 就是两个 h1。
  忘了也没关系，发布时会提示，加 `--strip-h1` 能自动删。
- 章节从 `##` 开始。
- frontmatter 每个值必须**单行**、不能含 `---`（线上解析器是手写的，值里一个换行
  就能把后面所有字段冲掉）。模板已经做了清洗，手改的时候注意。
- 这个库特意把「属性」编辑器关成了源码模式（`propertiesInDocument: source`）：
  Obsidian 的属性面板会把 `tags: ["a","b"]` 重排成多行 YAML，那样线上直接解析不出标签。
  **别把它改回 visible。**

## 发布

**双击桌面上的「发布台」图标** —— 会开一个没有地址栏、没有标签页的独立窗口：
左边草稿、中间用站点真实样式做的预览、右边算好的字段和写法体检。

第一次点要等几秒（起服务），之后就是秒开。服务会一直挂在后台（约 76MB），
要停就在任务管理器里结束占 4000 端口的那个 node。

命令行等价物：

```bash
cd web
npm run post:ui
```

发布台摆在 Obsidian 旁边用 —— 这边 `Ctrl+S`，那边自动刷新预览。

或者命令行：

```bash
cd web
npm run post                                       # 交互式，列草稿 → 预检 → 发
node scripts/publish-post.mjs <文件名> --dry-run    # 只看会做什么，不碰服务器
node scripts/publish-post.mjs <文件名> --preview    # 写进本地 content/posts 看真实排版（未上线）
node scripts/publish-post.mjs <文件名>              # 真发
```

发完归档：`bash scripts/pull-content.sh --commit`
