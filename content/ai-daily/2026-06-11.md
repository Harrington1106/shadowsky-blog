## 🔥 重磅发布

### 1. Anthropic Claude 4 系列全面开放 API

Anthropic 正式发布 Claude 4 系列（Opus 4 / Sonnet 4），在推理、编程和长文本理解方面大幅提升。Opus 4 在 MATH、HumanEval 等基准测试中刷新 SOTA，支持 200K 上下文窗口，多模态能力进一步增强。API 价格较上代降低 40%。

> 2.3K 讨论 · 2 小时前

---

### 2. MCP 协议成为 AI Agent 工具调用事实标准

Anthropic 推出的 Model Context Protocol (MCP) 正在成为 AI Agent 与外部工具交互的行业标准。包括 Claude Code、Hermes、Codex CLI 在内的主流 AI 编程工具已全面支持 MCP。社区已贡献超过 500 个 MCP Server，覆盖数据库、浏览器、文件系统等场景。

> 1.8K 讨论 · 5 小时前

---

### 3. OpenAI 推出 GPT-5 多模态旗舰模型

OpenAI 发布 GPT-5，统一了 GPT 系列和 o 系列模型。支持文本、图像、音频、视频多模态输入输出，推理能力显著提升。在复杂科学问题、数学证明和代码生成方面表现突出。同步推出 GPT-5 Mini，兼顾性能与成本。

> 5.1K 讨论 · 1 天前

---

### 4. Google DeepMind 发布 Gemini 3 Ultra —— 全面超越人类专家的推理能力

Gemini 3 Ultra 在 GPQA、MMLU-Pro 等权威基准测试中首次超越人类专家水平。支持 100 万 token 上下文，原生多模态推理，并在医学诊断、法律分析和科学研究方面展现出接近专业人员的判断力。

> 3.7K 讨论 · 2 天前

## 📊 行业趋势

### 11. 🤖 AI Coding Agent 进入实用化阶段

Claude Code、Codex CLI、Hermes、OpenCode 等 AI 编程 Agent 从实验走向生产。企业开始建立 Agent 质量门禁、沙箱环境和 Skill 复用机制。预计 2026 年 Q3 将有超过 40% 的开发团队在日常工作中使用 AI Agent。

---

### 12. 🔌 MCP 生态爆发式增长

Model Context Protocol 正在重塑 AI 工具的连接方式。从数据库到浏览器，从文件系统到云服务，超过 500 个 MCP Server 覆盖主流工具链。Anthropic 透露将在下一版本中支持流式 Tool Call 和双向通信。

---

### 13. 🏠 本地模型部署门槛持续降低

llama.cpp、Ollama、vLLM 等推理框架持续优化，消费级 GPU 即可运行 70B+ 参数模型。GGUF 量化格式日趋成熟，4-bit 量化模型在 MMLU 等基准上仅损失 2-3% 精度。本地 AI 正在从极客玩具走向实用工具。
