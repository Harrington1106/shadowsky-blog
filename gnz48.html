架构原理

1. 定时任务 (Cron Job)：每天凌晨 2 点在你的主机自动执行爬虫。
2. Python 获取并格式化：使用 BeautifulSoup 解析票务页面并用 ics 库写出静态文件。
3. Nginx 托管分发：配置你域名的 Nginx，直接把生成的 team_g.ics 开放给公网订阅。

# 服务器 CronJob 配置：
0 2 * * * /usr/bin/python3 /data/teamg/sync.py

核心 Python 爬虫生产代码 (复制即用)

python3 + ics 
import datetime
import requests
from bs4 import BeautifulSoup
from ics import Calendar, Event

# 官方票务地址（此处为示例，需根据官方当时页面结构抓取）
URL = "https://m.gnz48.com/tickets/index" 
HEADERS = {
    "User-Agent": "Mozilla/5.0 (iPhone; CPU iPhone OS 16_0 like Mac OS X) AppleWebKit/605.1.15"
}

def fetch_and_build():
    response = requests.get(URL, headers=HEADERS)
    response.encoding = 'utf-8'
    soup = BeautifulSoup(response.text, 'html.parser')
    
    cal = Calendar()
    
    # 假设解析出页面里的公演元素列表
    # (真实环境需要根据 gnz48.com 页面真实 div class 属性调整)
    events_element = soup.select(".ticket_item_list")
    
    for item in events_element:
        title = item.select_one(".title").text.strip()
        time_text = item.select_one(".time").text.strip() # "2026-07-11 19:30"
        
        # 仅截获 Team G 公演
        if "Team G" in title or "G队" in title:
            event = Event()
            event.name = title
            event.begin = datetime.datetime.strptime(time_text, "%Y-%m-%d %H:%M:%S")
            event.location = "广州 GNZ48 星梦剧院"
            event.description = f"公演详情请参见官网门票页。\\n应援色：亮绿色！"
            
            cal.events.add(event)
            
    # 输出到 Nginx 托管的静态路径中，即可支持全球订阅
    with open("/var/www/html/calendar/team_g.ics", 'w', encoding='utf-8') as f:
        f.writelines(cal.serialize_iter())
    print("日历同步成功！")

if __name__ == "__main__":
    fetch_and_build()

Nginx 部署支持 (CORS 跨源与标准 MIME)

当用户在 Apple/Google 日历填写你的订阅地址时，客户端可能会进行安全检查。在你的 Nginx Server block 中，为你的日历静态路由配置以下响应头。这能保证移动设备可以顺利请求日历流：

location /calendar/ {
# 声明正确的 iCal Content-Type 保证手机客户端正确识别
default_type text/calendar;
# 允许前端网站直接请求获取
add_header 'Access-Control-Allow-Origin' '*';
add_header 'Access-Control-Allow-Methods' 'GET, OPTIONS';
}
