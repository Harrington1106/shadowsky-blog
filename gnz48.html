系统已部署在 shadowquake.top — 架构说明

以下为实际运行在服务器上的 Python 定时任务 + Nginx 分发架构，每天自动更新日历。

1

架构原理

1. 定时任务 (Cron Job)：每天凌晨 02:17 执行 sync.py。
2. Python 读取 schedule.json：结合排班数据直接生成标准 ICS 文件（不依赖第三方库）。
3. Nginx 托管分发：配置 /calendar/ 路径，声明 text/calendar MIME 类型 + CORS 跨域。

# 服务器 CronJob 配置：
17 2 * * * /usr/bin/python3 /www/wwwroot/47.118.28.27/calendar/sync.py >> /var/log/gnz48_sync.log 2>&1
2

实际运行的 Python 同步脚本

python3 stdlib only 
import json, os
from datetime import datetime, timedelta, timezone

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
SCHEDULE_FILE = os.path.join(BASE_DIR, "schedule.json")
OUTPUT_FILE  = os.path.join(BASE_DIR, "team_g.ics")
TZ_CST = timezone(timedelta(hours=8))  # Asia/Shanghai
DOMAIN = "shadowquake.top"

def load_schedule():
    with open(SCHEDULE_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def build_ics(shows):
    lines = ["BEGIN:VCALENDAR", "VERSION:2.0",
             "PRODID:-//GNZ48 Team G//Theater Show Calendar//CN"]
    for show in shows:
        begin = datetime.strptime(f"{show['date']} {show['time']}:00",
                                   "%Y-%m-%d %H:%M:%S").replace(tzinfo=TZ_CST)
        end = begin + timedelta(hours=2, minutes=30)
        dtstart = begin.astimezone(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
        dtend   = end.astimezone(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
        desc = "\\n".join([
            f"公演：《{show['stage']}》",
            f"类型：{show['type']}",
            f"成员阵容：{'、'.join(show['cast'])}",
            f"备注特企：{show['note']}",
            f"购票通道：https://m.gnz48.com/tickets/detail/{show['ticketId']}",
        ]).replace("\\", "\\\\").replace(";", "\\;").replace("\\n", "\\\\n")
        lines += [
            "BEGIN:VEVENT",
            f"UID:teamg-{show['id']}@shadowquake.top",
            f"DTSTART:{dtstart}", f"DTEND:{dtend}",
            f"SUMMARY:[GNZ48] {show['title']}",
            f"DESCRIPTION:{desc}", f"LOCATION:{show['location']}",
            "BEGIN:VALARM", "TRIGGER:-PT2H", "ACTION:DISPLAY",
            "DESCRIPTION:公演即将开场！", "END:VALARM", "END:VEVENT",
        ]
    lines.append("END:VCALENDAR")
    with open(OUTPUT_FILE, "w", encoding="utf-8") as f:
        f.write("\\r\\n".join(lines) + "\\r\\n")

if __name__ == "__main__":
    build_ics(load_schedule())
    print("日历同步成功！")

Nginx 部署支持 (CORS 跨源与标准 MIME)

当用户在 Apple/Google 日历填写你的订阅地址时，客户端可能会进行安全检查。在你的 Nginx Server block 中，为你的日历静态路由配置以下响应头。这能保证移动设备可以顺利请求日历流：

location /calendar/ {
# 声明正确的 iCal Content-Type 保证手机客户端正确识别
default_type text/calendar;
# 允许前端网站直接请求获取
add_header 'Access-Control-Allow-Origin' '*';
add_header 'Access-Control-Allow-Methods' 'GET, OPTIONS';
}
